# ExploraRutas

Aplicación Android nativa desarrollada en Java con vistas XML para descubrir rutas de senderismo cercanas. Permite consultar una lista de rutas, ver su detalle y filtrarlas por dificultad. Diseñada para amantes de la naturaleza.

## Tecnologías utilizadas
- **Lenguaje:** Java
- **Interfaz:** XML Layouts
- **SDK:** Android API 24+ (Android 7.0)
- **Diseño:** Material Design
- **Recursos:** Internacionalización (Español / Inglés), Vector Assets y Bitmaps.

## Cómo ejecutar la aplicación

1. Clona el repositorio:
   git clone https://github.com/julio-carmona47/PMDM_P1_JulioCarmona.git

2. Abre el proyecto en Android Studio.
3. Sincroniza el proyecto con Gradle (File > Sync Project with Gradle Files).
4. Ejecuta la aplicación en un emulador o dispositivo físico con API 24 o superior.
5. Para probar la internacionalización, cambia el idioma del emulador a inglés o español.
